## 📌 About This Activity

> I asked **ChatGPT** to make a very simple 5-step diagram of the disease process of **diabetes mellitus** for non-medical people. Then I asked **Claude** to **improve the prompt** and create its own version, and compared the results.

### 🔄 The 5-Step Flow (Claude's version)

```
🍎 Food becomes sugar  ➜  🔓 Insulin is released  ➜  🔒 Insulin stops working well  ➜  🧱 Sugar builds up  ➜  ⚠️ Slow damage
```

### 📊 Comparison

| Criteria | Result |
|:---|:---|
| **Clarity** | Claude's diagram was clearest: one short sentence per step and color coding. |
| **Detail** | ChatGPT's images were richer, with realistic illustrations. |
| **Accuracy** | All were broadly correct for Type 2 diabetes. |
| **Usefulness** | Claude's diagram and ChatGPT's Output 2 worked best for non-medical audiences. |

## 💡 What Have I Learned?

| 🔑 Key Skills | 🧗 Challenge & Solution | 🚀 Future Use |
|---|---|---|
| Prompt engineering and comparing AI outputs on clarity, detail, accuracy, and usefulness. | The first prompt was vague, so the output had small, crowded text. Claude suggested setting the audience, word limits, and design rules. | I can use AI to build patient education materials, as long as I verify the content. |

- ✅ **Specific prompts** (audience, word limit, layout) give better results.
- ✅ Different AI tools have different strengths, so comparing them helps.
- ✅ AI output must always be **checked for accuracy** before use in healthcare.
